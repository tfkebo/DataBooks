# IMDb Movie Analysis 

## About

This project analyzes the IMDb Top 1000 Movies dataset to explore trends in ratings, genres, directors, runtime, and revenue.

## Goal

Identify patterns among highly rated movies using exploratory data analysis.

## Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
