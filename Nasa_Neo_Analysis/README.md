# NASA Near-Earth Objects Analysis ☄️

## About

This project analyzes NASA's Near-Earth Object (NEO) dataset to explore asteroid characteristics and identify patterns related to hazardous asteroids.

## Goal

Understand how asteroid size, velocity, and distance relate to hazard classification.

## Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
