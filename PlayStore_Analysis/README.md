# Google Play Store Analysis 

## About

This project analyzes the Google Play Store dataset to explore app ratings, installs, categories, pricing, and reviews.

## Goal

Identify trends and patterns among mobile applications using exploratory data analysis.

## Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
